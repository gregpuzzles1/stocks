# Stocks

A personal stock portfolio tracker.

## Desktop app (top level)

- `stocks.py`: a PyQt5 desktop app. It shows a table of your holdings with live Finnhub prices, profit/loss, company logos and a pie chart.
- `holdings.json`: the holdings that app saves.
- `requirements.txt`, `Dockerfile` and `StockDashboard.pi5`: packaging files for running it, apparently on a Raspberry Pi.
